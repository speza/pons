# Diagrams

Keep each editable source beside its Markdown-ready export, using the same
basename. For example, `pons-system.html` is the source for `pons-system.svg`.

Embed the SVG in Markdown and link the source nearby. Commit both files, and
regenerate the SVG whenever the source changes. An Excalidraw diagram can use
`.excalidraw` as its source file with the same convention.
